Calendar Overview

Calendar Overview

Your Calendar shows your shift schedule, events, trade requests, and shift details in one place.

  • Tap a day to view shift details
  • Use Manage Calendars to control personal calendars
  • Use Manage Events to add or review personal events

Manage Calendars

Manage Calendars

Manage Calendars is where you create personal calendars, import outside calendars, and control what appears on your Platoon calendar.

  • Create calendars for overtime, kids sports, appointments, or vacations
  • Import events from an outside calendar app
  • Turn calendars on or off
  • Review how each calendar affects trade warnings

Create a Personal Calendar

Personal calendars help separate different parts of your life so your schedule stays organized.

  • Give the calendar a clear name
  • Choose a color
  • Decide whether it should affect trade warnings
  • Choose whether it appears on your calendar

Trade Impact

Visibility & Trade Impact

Trade impact controls how events on that calendar affect trade decisions.

  • Block: marks the time as unavailable for trades
  • Warn: shows a caution but still allows trading
  • None: shows the event without affecting trades

Manage Events

Manage Events is where you can search, filter, review, and add personal events.

  • Search for events
  • Filter by calendar or event type

  • Start a new personal event

New Personal Event

Create a Personal Event

Personal events can be single-day, multi-day, all-day, or recurring.

  • Add title, date, time, and location
  • Choose which personal calendar it belongs to
  • Use repeating events when needed
  • Events can appear directly on your Calendar
